# นับแต้มสนุกเกอร์ (Snooker Scorer)

กระดานนับแต้มสนุกเกอร์บนเว็บ แตะที่สีลูกที่แทงลงเพื่อบันทึกแต้ม ใช้ได้ทั้งภาษาไทยและอังกฤษ

A browser-based snooker scoreboard. Tap the ball you potted and the score follows the rules. Thai / English.

## ฟีเจอร์ / Features

- เลือกโหมดลูกแดง **6 หรือ 15 ลูก** — pick a 6-red or 15-red frame
- บังคับลำดับ **แดง → สี → แดง → สี** และเริ่มที่แดงเสมอเมื่อเปลี่ยนตาผู้เล่น
- แทงผิดจังหวะ = **ฟาวล์อัตโนมัติ** หักแต้มจากคนแทงเอง (อย่างน้อย 4 แต้ม)
- ปุ่มลูกขาว หัก 4 แต้ม, ปุ่มฟาวล์เลือกแต้มเอง 4–7
- **ลูกฟรี** (free ball) และ **ลูกดำรีสปอต** เมื่อแต้มเท่ากันตอนจบเฟรม
- เบรกปัจจุบัน / เบรกสูงสุด, แต้มคงเหลือบนโต๊ะ, ส่วนต่างคะแนน, ประวัติการเล่น
- ย้อนกลับได้ทีละสเต็ป, ปรับแต้มด้วยมือ (ติดลบได้), จำสถานะไว้ในเบราว์เซอร์

## การใช้งาน / Running it

ไฟล์เดียวจบ ไม่ต้อง build ไม่ต้องติดตั้งอะไร — เปิด `index.html` ในเบราว์เซอร์ได้เลย

Single file, no build step. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```
